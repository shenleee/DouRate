DouRate 安装 / Installation
===========================

DouRate 现在只通过 Chrome 应用商店发布，安装后会自动更新：
DouRate is now published only on the Chrome Web Store and updates automatically:

https://chromewebstore.google.com/detail/bdjlmdohbjllclekdldokapgdaacelnn?utm_source=github&utm_medium=installation&utm_campaign=launch

本仓库里的源码和 Releases 中的安装包都是旧版本，不再更新。之前用 ZIP 手动安装过的话，请在 chrome://extensions 移除旧版，再从商店安装；重装后需要在弹窗里重新下载一次 IMDb 数据。
The source in this repository and the packages under Releases are older versions and are no longer updated. If you installed an earlier ZIP manually, remove it at chrome://extensions and install from the store; download the IMDb data again from the popup afterwards.

使用说明、FAQ 和故障排查 / Usage, FAQ and troubleshooting: https://github.com/shenleee/DouRate/wiki
